What the predictions say

A correction made after publication can act as a fingerprint of a measurement. If two published figures rest on the same meters, a correction to the metering data shows up in both on the same day and with the same size. E1 and E2 test this pilot result on new data from the existing capture of datasets 358 and 359. E3–E6 cover datasets 124, 193, 360, 361 and 362, whose capture started on 16 October 2026.

All six are scored after 15 November 2026, for captures from 16 October to 14 November 2026. Every result will be reported, including the predictions that miss.

Addendum 1 records a deviation: the first capture of the new datasets ran before the analysis script was written. A single capture cannot show a correction, so no deciding data had been seen. Addendum 2 replaces the E6 heading "same root by the publisher's description" with "same calculation formula", because the dataset pages describe the formula, not the measurements.

How to check

Download a file and compute its sha256: sha256sum on Linux, shasum -a 256 on macOS or Get-FileHash in Windows PowerShell. The e-mail timestamps can only be shown by the author. The commit that added these files to the public repository source-count/source-count.github.io carries a time set by the author's own computer.

The independent timestamps are the Internet Archive copies listed with each file, and a copy of this page (16:40:53 UTC). All were saved on 16 October 2026 between 16:40 and 16:44 UTC.

For E3–E6 this is before the second capture of the new datasets on 17 October, so before any correction to those datasets existed. For E1–E2 it is not: the existing daily capture of datasets 358 and 359 last wrote to its file on 16 October at 16:06 UTC, so the first data that decides E1–E2 already existed when the archive copies were made. That data has not been read. The predictions themselves were written at 12:37 UTC and e-mailed at 12:41 UTC, before that capture.

The archive serves the raw copies gzip-compressed; after decompression their sha256 values match the ones above.

The files name the analysis scripts by their sha256. The scripts will be published with the results.
